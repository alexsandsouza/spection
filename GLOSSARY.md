# Glossary

- **SDD:** Spec-Driven Development; specifications guide implementation and verification.
- **HLD:** High-Level Design; architecture and system boundaries.
- **LLD:** Low-Level Design; component contracts and implementation details.
- **ADR:** Architecture Decision Record; traceable design trade-offs.
- **PRD:** Product Requirements Document; documented product expectations.
- **Agent Skill:** Reusable, scoped instruction set for an AI agent.
- **Harness Engineering:** Design of agent instructions, tools, controls, context and feedback loops.
- **Quality Gate:** Evidence-based check required before progression.
- **Traceability:** Mapping from requirements to changes, tests and results.
