# SPECTION Portal

Run `npm install` then `npm run dev` from `site/`. Run `npm run build` to export into `out/`. For GitHub Pages, set `NEXT_PUBLIC_BASE_PATH=/spection` before building. The first version links to versioned GitHub documentation; it has no backend or AI API.
