# New feature: Specify → Plan → Tasks → Implement → Verify

1. Identify requirements and owner; record affected users.
2. Write acceptance scenarios including errors and permissions.
3. Check architecture impact and create ADR if needed.
4. Break scope into small, independently testable tasks.
5. Develop in a reviewable branch with bounded agent/tool permissions.
6. Execute applicable unit, integration, security and accessibility checks.
7. Update traceability and request reviewer acceptance.

**Never:** treat generated code as validation, invent tests, or deploy implicitly.
