# Release: Evidence → Approval → Deploy → Observe

1. Confirm reviewed requirements and acceptance results.
2. Record test commands/results, open risks and known limitations.
3. Review access control, secrets, dependency risk and privacy obligations.
4. Document migration, rollback, backup and incident contacts.
5. Obtain explicit authorization before deployment or destructive changes.
6. Observe real metrics and incidents; plan follow-up changes.

SPECTION Kit does not deploy anything automatically.
