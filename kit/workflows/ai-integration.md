# AI integration: Need → Options → Threats → Evals → Pilot

1. Prove the product needs a model or agent instead of deterministic software.
2. Compare candidate providers and self-hosting for quality, price, latency, privacy and operations.
3. Define user permissions, tool permissions, data flows and trust boundaries.
4. Assess prompt injection, untrusted retrieval, model outputs and tool side effects.
5. Build an approved evaluation dataset and measurable thresholds before implementation.
6. Pilot within a narrow scope, record errors and costs, design fallback and human overrides.
7. Review evidence with stakeholders before public or production enablement.

Do not imply that guardrails alone make an AI system safe.
