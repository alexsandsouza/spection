# SPECTION Workflow Catalog

Independent, composable workflows. Choose the entry point based on the real task.

| Workflow | Entry condition | Deliverables | Exit condition |
|---|---|---|---|
| [New project](new-project.md) | A problem needs validation | Brief, PRD, HLD, ADR, LLD | Reviewed specs |
| [New feature](new-feature.md) | Approved RF or RNF | Feature spec, plan, tasks, tests | Evidence + human sign-off |
| [Bug fix](bug-fix.md) | Reproducible incident | Reproduction, root cause, minimal fix | Regression test and review |
| [AI integration](ai-integration.md) | Justified need for AI capability | Model and data options, evals, threat model | Safe pilot and go/no-go |
| [Release](release.md) | Reviewed implementation | Evidence, change log, rollback | Explicit release approval |

Human approval cannot be bypassed by an agent result.
