# Contributing to SPECTION

Thank you for contributing. Propose changes in an issue or pull request with the problem, proposed design, acceptance criteria, test evidence and documentation impact.

- Use small focused pull requests.
- Preserve spec IDs and traceability.
- Never commit credentials or confidential data.
- Include instructions to reproduce any claimed successful check.
- Treat model-generated content as a draft requiring review.
- Be respectful, constructive and accessible in discussions.

Contributions are subject to the [MIT License](LICENSE).
